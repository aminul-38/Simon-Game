# Simon Game

A simple yet engaging memory-based game where players need to repeat the pattern shown by the game. The pattern gets longer with each successful round!

## 🕹️ How to Play
1. Press any key (or tap on mobile) to start the game.
2. The game will highlight a button in a specific color—watch carefully!
3. Click the buttons in the exact order shown.
4. If you repeat the pattern correctly, the game will add another step.
5. If you make a mistake, the game ends, and you can restart.

## 📁 Project Structure
- `index.html` → The main HTML file for the game structure.
- `style.css` → Main styles for desktop view.
- `mobile.css` → Responsive styles for mobile screens.
- `index.js` → JavaScript file containing game logic.
- `sounds/` → Folder containing sound effects for game interactions.

## 💻 Technologies Used
- **HTML** → Structuring the game layout.
- **CSS** → Styling and animations.
- **JavaScript & jQuery** → Game logic and interactivity.

## 🎮 Features
- Randomized color sequence generation.
- Interactive UI with animations.
- Sound effects for better user experience.
- Responsive design for both desktop and mobile users.
